# AttendX-Test-Scripts

## Project Description
This repository contains sample automation scripts for the AttendX Student Attendance App.
The scripts are kept under version control to avoid overwriting shared work.

## Test Scripts
- `login_test.py` checks a basic login scenario.
- `attendance_test.py` checks attendance marking.

## How to Run
Use Python to execute either script directly:

```bash
python login_test.py
python attendance_test.py
```
